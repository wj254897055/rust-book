关于本版本

本版内容假定你使用的是 Rust 1.97.0（2026-07-09 发布）或更高版本，并且所有项目的 Cargo.toml 中均设置了 edition = "2024"，以便采用 Rust 2024 Edition 的惯用法。有关安装或更新 Rust 的说明，请参阅 第 1 章的“安装”一节； 有关 Edition 的信息，请参阅 附录 E。

HTML 格式可在 https://doc.rust-lang.org/stable/book/ 在线获取，也可以通过 rustup 安装的 Rust 离线阅读；运行 rustup doc --book 即可打开。

还有若干 社区翻译版本 可供选择。

本书的纸质版和电子书版由 No Starch Press 出版。

想要更具互动性的学习体验？可以试试另一个版本的 Rust Book，它包含测验、高亮、可视化等内容： https://rust-book.cs.brown.edu。
